# Quiz Geneartor AI

AI turns uploaded study material into focused multiple-choice practice.

## Features

- PDF, DOCX and TXT material extraction
- Difficulty selection
- Topic selection
- Practice mode
- Analytics and topic performance
- Detailed answer review
- Streamlit interface
- GitHub / Streamlit Community Cloud friendly structure

## Local run

```bash
python -m venv .venv
```

Windows:

```bash
.venv\Scripts\activate
pip install -r requirements.txt
```

Then:

```bash
streamlit run app.py
```

## Deployment

For Streamlit Community Cloud, deploy this repository.
